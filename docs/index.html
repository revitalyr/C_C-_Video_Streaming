🎬 Real-time Video Streaming System

High-performance H.264 video streaming over UDP/RTP with C++20 modules

System Overview

A high-performance real-time video streaming system implemented in modern C++ with C++20 modules. The system focuses on low-latency H.264 streaming over UDP/RTP with custom network simulation capabilities.

Key Capabilities

  • Low-latency H.264 video encoding and decoding via FFmpeg
  • RTP/RTCP protocol implementation for packetization
  • UDP socket abstraction with async I/O support
  • Jitter buffer for packet reordering and loss concealment
  • Network simulation with configurable loss, delay, and jitter
  • Coroutine-based async operations (C++20)
  • SDL2-based visual rendering pipeline
  • RTSP client and server support

Technology Stack
