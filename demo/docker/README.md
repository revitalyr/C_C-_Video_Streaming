# Docker Demo

Этот проект демонстрирует использование Docker для запуска простого приложения на Node.js.

## Установка и Запуск

1. Склонируйте репозиторий или создайте папку `demo/docker`.
2. Создайте файлы `Dockerfile`, `README.md` и `run.sh` согласно инструкциям.
3. Выполните скрипт для запуска приложения:
   ```bash
   ./run.sh
   ```

4. Откройте браузер и перейдите по адресу `http://localhost:3000`, чтобы увидеть работу приложения.

## Требования

- Docker установлен на вашем компьютере.
