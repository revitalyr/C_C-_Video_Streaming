# Docker Demo

Этот `docker-compose` файл запускает полноценную среду для видео стриминга, состоящую из отправителя и получателя.

## Установка и Запуск

1.  Убедитесь, что у вас установлен Docker и Docker Compose.
2.  Из корневой директории проекта выполните команду:

   ```bash
   docker-compose -f demo/docker/docker-compose.yml up --build
   ```

3.  Эта команда соберет Docker-образ с вашим приложением и запустит два контейнера: `sender` и `receiver`.

4.  Чтобы остановить демонстрацию, нажмите `Ctrl+C`.

## Требования

- Docker установлен на вашем компьютере.
